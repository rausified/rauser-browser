# Task bar

Built: reusable literal sidebar `[[commands]]` with a revision-checked Settings editor and host-resolved slash invocation;
a free-text field under the panel's page area runs the configured harness on the user's typed instruction through the service (`start_task`, run kind `task`, additive within protocol v8), with optional page context in `page.md` (explicit no-page tasks omit it);
Tasks shows progress and a plain-text report;
optional task completion notifications work while the panel is closed;
finishing writes nothing, and an explicit Save to note appends the retained report to its source page note
