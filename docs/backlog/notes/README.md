# Backlog notes

One file per entry: a cycle observation, a handoff, an ask. `scripts/dev/queue
backlog` appends every `*.md` here except this README, in file-name order,
under "Cycle notes" at the end of the rendered `BOSUN_FEATURE_BACKLOG.md`.

Name a file `YYYY-MM-DD-<short-slug>.md` and start it with a `###` heading
(for example `### Cycle observations (2026-11-04 — focus sessions)`). Two
branches that each add a note never touch the same file, so they never
conflict; edit an existing note only to correct it. Older observations stay
where they were, in `docs/backlog/frame.md`. Like the frame, a note must not
hold an open `- [ ]` item (open work is a bead) or name a bead the queue lacks.
